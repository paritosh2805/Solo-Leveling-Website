# Solo Leveling Website
by Paritosh Asthana

An immersive fan website dedicated to the anime **Solo Leveling**, featuring stunning animations, dynamic interactions, and a smooth user experience.

## 🚀 Tech Stack

- **React.js** – Component-based UI development
- **Tailwind CSS** – Utility-first styling for fast and responsive design
- **GSAP** – High-performance animations and smooth transitions

## 🔋 Features

### 🎭 **Engaging Animations**
- **Scroll-Based Animations** – Dynamic effects triggered by user scrolling.
- **Clip Path Shaped Animations** – Unique geometric transitions for stunning visuals.
- **3D Hover Effects** – Interactive transformations for a modern feel.
- **Video Transitions** – Seamlessly integrated video elements to enhance storytelling.
- **Smooth UI/UX** – Polished interactions ensuring an intuitive journey.
- **Completely Responsive** – Flawless adaptation across all devices.

### 📌 **Code Architecture & Reusability**
- Modular and reusable components for easy maintenance and scalability.
- Optimized structure following best coding practices.
- Efficient state management for performance enhancements.
